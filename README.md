# 🚀 Boot.dev

Bem-vindo ao meu repositório de estudos do [Boot.dev](https://www.boot.dev/u/ewertonangelodev)! Aqui documento meu progresso, resolvo desafios de código, salvo exercícios práticos e desenvolvo projetos das trilhas de aprendizado da plataforma.

---

## 🎯 Objetivo
Construir uma base sólida em engenharia de software e infraestrutura, focando em desenvolvimento backend, automação, conteinerização e práticas modernas de DevOps utilizando **Python** e **Go**.

---

## 🗺️ Trilha de Estudos (DevOps Engineer Path)

O progresso da trilha é dividido entre fundamentos de programação, arquitetura de sistemas e ferramentas de operações:

- [x] **Python for Beginners** - Lógica e fundamentos da linguagem.
- [x] **Linux & Git** - Comandos do sistema operacional, terminal e controle de versão.
- [x] **Object-Oriented Programming (OOP)** - Conceitos avançados em Python.
- [x] **Learn Go (Golang)** - Sintaxe, ponteiros, structs e concorrência.
- [x] **HTTP Clients & Servers** - Construção de APIs, manipulação de JSON, arquitetura e autenticação.
- [x] **SQL & Databases** - Modelagem de dados e consultas.
- [ ] **Docker & Containers** - Empacotamento e isolamento de aplicações *(Em andamento)*.
- [ ] **Logging & Observability** - Monitoramento e métricas.
- [ ] **AWS & Cloud Infrastructure** - Provisionamento em nuvem.
- [ ] **CI/CD & Kubernetes** - Orquestração e entrega contínua.

---

## 🛠️ Tecnologias Utilizadas

* **Linguagens:** Python, Go, SQL, Bash/Shell.
* **Ferramentas & SO:** Linux (WSL2), Git, Docker, AWS.
* **Ambiente de Desenvolvimento:** VS Code, Zed.
